## كيف نعامل الاشتراكات والتجديد (GM-044)
- **الاشتراك السنوي المدفوع مقدماً** (1,199 أو 790 أو دفع المضيف السنوي): يوم القبض يدخل كله في 2300 (مؤجل)، وآخر كل شهر ننقل 1/12 منه للإيراد (4210/4220/4230). السبب: الخدمة تُقدَّم على 12 شهر، والعميل ممكن يلغي.
- **الشهري للمضيف:** يدخل إيراد 4230 مباشرة في شهره.
- **العتاد يبقى ملكنا:** شراء الستاند/الشريحة يدخل 1300، ولما يتركب عند العميل ينتقل 1400، ويُستهلك على مدة الاشتراك (5700). مدة الاستهلاك «غير مؤكد» — يحددها المحاسب المرخص حسب SOCPA/IFRS.
- **الاستبدال والتركيب** على حسابنا: 5600.
- ما فيه حساب «بيع ستاند»؛ 4100 يبقى لأي بيع مستقبلي منفصل لو انعتمد.

## أعمدة الدفتر
| العمود | المعنى |
|---|---|
| entry_no | رقم القيد (JE-0001 ...)، القيد الواحد عدة أسطر بنفس الرقم |
| date | YYYY-MM-DD |
| account_code / account_name | من الدليل أعلاه |
| debit_sar / credit_sar | سطر فيه مدين أو دائن فقط، والثاني فاضي |
| description | البيان |
| reference | رقم الفاتورة أو إيصال المصروف |
| owner_approved | yes / no |

**قاعدة التوازن:** لكل entry_no: مجموع المدين = مجموع الدائن.

## أمثلة الاشتراك (للشرح فقط، ليست في الدفتر)
**3) قبض اشتراك حزمة المحل السنوي، INV-000N:**
```
JE-000N,YYYY-MM-DD,1110,البنك,1199,,اشتراك سنوي حزمة المحل,INV-000N,yes
JE-000N,YYYY-MM-DD,2300,إيراد اشتراكات مؤجل,,1199,اشتراك سنوي حزمة المحل,INV-000N,yes
```

```
JE-000M,YYYY-MM-DD,2300,إيراد اشتراكات مؤجل,99.92,,إثبات شهر من اشتراك سنوي,INV-000N,yes

```
