## أعمدة الدفتر
| العمود | المعنى |
|---|---|
| entry_no | رقم القيد (JE-0001 ...)، القيد الواحد عدة أسطر بنفس الرقم |
| date | YYYY-MM-DD |
| account_code / account_name | من الدليل أعلاه |
| debit_sar / credit_sar | سطر فيه مدين أو دائن فقط، والثاني فاضي |
| description | البيان |
| reference | رقم الفاتورة أو إيصال المصروف |
| owner_approved | yes / no |

**قاعدة التوازن:** لكل entry_no: مجموع المدين = مجموع الدائن.

## مثالان توضيحيان (للشرح فقط، ليسا في الدفتر، والمبلغ رمز X وليس سعراً)
**1) بيع ستاند بالتحويل البنكي، فاتورة INV-0001:**
```
JE-0001,YYYY-MM-DD,1110,البنك,X,,بيع ستاند تقييم,INV-0001,yes
JE-0001,YYYY-MM-DD,4100,إيراد بيع مرة وحدة,,X,بيع ستاند تقييم,INV-0001,yes
```
**2) شراء شرائح من مورد بالآجل:**
```
JE-0002,YYYY-MM-DD,1300,مخزون الشرائح والستاندات,Y,,شراء شرائح,إيصال المورد,yes
JE-0002,YYYY-MM-DD,2100,ذمم الموردين,,Y,شراء شرائح,إيصال المورد,yes
```
