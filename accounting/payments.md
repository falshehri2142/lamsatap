# سجل الدفعات (`payments.csv`)

الملف فاضي عمداً: ما فيه أي دفعة حقيقية.

| العمود | المعنى |
|---|---|
| date | تاريخ استلام الدفعة بصيغة YYYY-MM-DD |
| invoice_no | رقم الفاتورة (INV-0001 ...) من `invoice-template.md` |
| client | اسم العميل كما في `clients/` |
| amount_sar | المبلغ المستلم بالريال (رقم فقط، بدون فواصل آلاف) |
| payment_method | bank_transfer / cash / other |
| bank_ref | رقم العملية البنكية فقط (لا رقم حساب ولا بطاقة ولا آيبان) |
| owner_confirmed | yes بعد ما يؤكد صاحب المشروع وصول المبلغ، وإلا no |

## القواعد
- لا تُضاف دفعة إلا بعد تأكيد صاحب المشروع (السكيل).
- كل دفعة مؤكدة لها قيد في `ledger.csv` بنفس رقم الفاتورة في عمود `reference`.
- الدفعة الجزئية: سطر لكل دفعة بنفس رقم الفاتورة.
