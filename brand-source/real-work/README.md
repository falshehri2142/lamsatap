# شغل حقيقي من صاحب المشروع

## 2026-09-28-awa-home-checkout-sign.jpg
لوحة «تأكيد الخروج الذكي» سواها صاحب المشروع لشقة صديقه (AWA HOME): شريحة NFC + باركود، في برواز ذهبي على الجدار.
قرار المدير العام (GM-049): الموقع يعرض **المنتج الحقيقي** بدل صور الضيافة العامة.

قبل أي استخدام علني (الموقع، الإعلانات):
1. **الباركود يتغطى أو ينشال** — لو أحد مسحه من الموقع، يقدر يرسل تأكيد خروج وهمي لشقة الصديق.
2. **اسم AWA HOME** ما يطلع إلا بموافقة مكتوبة من الصديق (رسالة واتساب تكفي كبداية)؛ بدونها نستخدم اسم عقار تجريبي.
3. **النصوص داخل اللوحة** لازم تطابق وعودنا المعتمدة: «إشعار فوري للمضيف» ما يطابق GM-017 (البلاغ يوصلنا ونحوّله للمضيف من جوال الشركة)، و«آمن وخاص» يحتاج صياغة معتمدة.
4. الصورة فيها انعكاس زجاج البرواز؛ الأفضل تصوير جديد بضوء النهار، أو بناء mockup نظيف من ملف التصميم الأصلي.
