# print/EXPORT.md: أداة التصدير `print/export.cjs`

أداة داخلية لإدارة الطباعة (GM-023 بند 3، GM-051). تاخذ أي قالب في `print/` وتطلّع منه:
- **PDF بالمقاس الحقيقي** من `@page` حق الصفحة نفسها، بالخلفيات، بدون هوامش ولا ترويسة ولا تذييل. ومعه **ملف المطبعة** (نزف وعلامات قص) لو القالب يدعمه.
- **PNG لكل ورقة** (`.p-sheet`) واسمها من `data-sign`، بأي دقة: `2x` لصور الموقع و`300dpi` للمطبعة، وبخلفية شفافة لو تبي.
- **صور السوشال**: صفحة مقاسها بالبكسل (مثل 1080×1080) تطلع بنفس المقاس بالضبط، بدون شفافية.

وبعد كل ملف تفحصه من الملف نفسه (المقاس، الشفافية، الدقة، صفحات PDF)، وتكتب النتيجة في `<name>.export.json`.
ما تنشر شي ولا ترفع شي (GM-006): كل شي على الجهاز.

## المتطلبات
- Node 22 أو أحدث (فيه `fetch` و`WebSocket` جاهزين). جربناها على Node v24.18.
- Chrome أو Edge مثبت. الأداة تلقاه لحالها، أو `--browser <المسار>`. جربناها على Chrome 153 وEdge 154 (ويندوز).
- **بدون npm** ولا أي مكتبة.

## أوامر جاهزة (من جذر المشروع)
```
# ملصقات المضيف: PDF + صورة لكل ملصق 2x (الموقع) و300dpi (المطبعة)، بخلفية شفافة
node print/export.cjs --url "print/host-stickers/index.html?client=example-flats" --out <مجلد> --pdf --png 2x,300dpi --transparent

# صور الموقع (print/renders/): صورة لكل قطعة باسمها بالضبط (--file)، والأوامر الخمسة كاملة في print/renders/SIZES.md
node print/export.cjs --url "print/host-signs/index.html?client=example-flats&sign=wifi&render=1" --out print/renders --png 2x --transparent --file wifi-stand.png --no-manifest

# ملفات الطباعة لكل قطعة (مثل ما انصدّرت 2026-09-28): PDF بالنزف في pdf/، وصورة 2x شفافة و 300dpi بدون شفافية في png/
node print/export.cjs --url "print/host-signs/index.html?client=example-flats&sign=wifi" --out print/host-signs/pdf --bleed --pdf --name wifi-stand
node print/export.cjs --url "print/host-signs/index.html?client=example-flats&sign=wifi" --out print/host-signs/png --png 2x --transparent --sign-names --name wifi-stand-2x
node print/export.cjs --url "print/host-signs/index.html?client=example-flats&sign=wifi" --out print/host-signs/png --png 300dpi --sign-names --name wifi-stand-300dpi

# الأوراق كلها مرة وحدة: اسم الملف = data-sign بس، مثل wifi-stand@2x.png
node print/export.cjs --url "print/host-signs/index.html?client=example-flats" --out <مجلد> --png 2x --transparent --sign-names

# ملف المطبعة: نزف 3mm وعلامات قص (bleed=1 في القالب)، و PDF فيه TrimBox و BleedBox
node print/export.cjs --url "print/host-signs/index.html?client=<الوحدة>" --out <مجلد> --bleed --pdf --png 300dpi

# نسخة الحفر (لون واحد)
node print/export.cjs --url "print/stand/index.html?client=<العميل>" --param mono=1 --out <مجلد> --pdf

# صور السوشال (الصفحة تحدد المقاس بالبكسل)
node print/export.cjs --url "print/social/<الصفحة>.html" --out <مجلد> --social

# فحص بس بدون تصدير: الأوراق وأسماؤها والخطوط وتنبيهات القالب
node print/export.cjs --url "print/host-signs/index.html?client=example-flats" --check
```
`node print/export.cjs --help` يعرض كل الخيارات.

## الخيارات
| الخيار | وش يسوي |
|---|---|
| `--url` | مسار القالب من جذر المشروع مع الـ query (`?client=...`). مو رابط موقع. |
| `--out` | مجلد المخرجات (ينسوى لو مو موجود). |
| `--name` | بداية أسماء الملفات. الافتراضي: `<مجلد القالب>-<client>` (ومعه `-mono`). |
| `--sign-names` | صور PNG باسم الورقة بس: `<sign>@2x.png`. |
| `--file <اسم.png>` | اسم ملف PNG بالضبط (مثل `wifi-stand.png` لصور الموقع). لورقة وحدة بدقة وحدة: الصفحة لازم تعرض ورقة وحدة (باراميتر القالب مثل `sign=wifi`، أو `--only`)، وإلا خطأ وما يصدّر شي. |
| `--pdf` | PDF بمقاس `@page`. |
| `--png 2x,300dpi` | صورة لكل ورقة بكل دقة. `1x` `2x` `3x` للموقع، و`300dpi` `600dpi` للمطبعة. |
| `--transparent` | خلفية الصفحة شفافة (RGBA). بدونه: RGB بدون شفافية. |
| `--social` | صور السوشال: 1x بالضبط، بدون شفافية، وسيط الشاشة. |
| `--bleed` | وضع المطبعة في القالب (`bleed=1`). غيّر الاسم بـ `--bleed-param`. |
| `--param k=v` | أي باراميتر ثاني للقالب، مثل `mono=1` أو `sign=wifi`. |
| `--selector` | الأوراق (الافتراضي `.p-sheet`). |
| `--only a,b` | صور أوراق معينة بأسمائها. PDF يطلع بكل صفحات القالب؛ للوحة وحدة استخدم باراميتر القالب نفسه (مثل `--param sign=wifi` في `print/host-signs`). |
| `--media` | `auto` (الافتراضي)، أو `print`، أو `screen`. شوف «الوسيط» تحت. |
| `--check` | فحص بدون تصدير. |
| `--force` | يصدّر حتى لو الصفحة فيها أخطاء. للتجربة بس، مو لملف المطبعة. |
| `--allow-net` | يسمح بطلبات برّا الجهاز (ممنوعة افتراضياً). |
| `--no-pdf-fix` | يخلي مقاس صفحة PDF مثل ما قرّبه المتصفح. |
| `--no-manifest` | بدون ملف `.export.json`. |
| `--wait` و`--timeout` و`--browser` | انتظار زيادة، ومهلة الجاهزية، ومسار المتصفح. |

نتيجة الأمر: `0` كل الفحص نجح، `1` خطأ في الصفحة أو فحص فشل، `2` خطأ في الأمر نفسه.

## أسماء الملفات
- PDF: `<name>.pdf`، وفي وضع المطبعة `<name>-bleed.pdf`.
- PNG: `<name>-<sign>@2x.png` و`<name>-<sign>@300dpi.png` (وفي وضع المطبعة `<name>-<sign>-bleed@300dpi.png`). مع `--sign-names`: `<sign>@2x.png`.
- السوشال: `<name>-<sign>.png` بدون `@`، لأن المقاس هو مقاس الصفحة.
- `<name>.export.json`: كل القياسات والفحوصات وتنبيهات القالب وتقرير القالب (`PRINT_REPORT`)، بمسارات نسبية بس.
- اسم الورقة من `data-sign` (حروف لاتينية)، وإلا `id`، وإلا `sheet-1` و`sheet-2`.

## الوسيط (screen أو print)
- `auto`: صور الموقع (`1x` `2x`) بشكل المعاينة على الشاشة، وصور المطبعة (`dpi`) بشكل الطباعة.
- السبب من القالب نفسه: لوحة الباب مدوّرة الزوايا على الشاشة (`border-radius` من `door.radius` في `print/dims.js`)، ومربعة في الطباعة (`print.css`، المطبعة تقص الزاوية). فصورة الموقع تطلع مدوّرة بزوايا شفافة، وصورة المطبعة كاملة.
- في الحالتين: شريط المعاينة `.p-screen` وحدود الأمان `.p-guide` وإطار الورقة ما يطلعون.

## اتفاق القالب (عشان الأداة تشتغل صح)
1. كل ورقة `.p-sheet` **بمقاس ثابت** (mm أو px). لو المقاس يتبع عرض النافذة (مثل `width: 100%`) الأداة ترفضها. وداخل صف flex: `flex: none`.
2. `data-sign` بحروف لاتينية وشرطة: هو اسم الملف.
3. `@page { size: W H }` (أو `setPageSize` في `print.js`). بدونه ما فيه PDF.
4. وضع المطبعة: الصفحة = القص + النزف + علامات القص. داخل كل ورقة `.s-trim` (أو `[data-trim]`) = صندوق القص، و`.s-art` (أو `[data-bleed-box]`) = صندوق النزف. والأداة تتأكد إن صندوق القص بنفس مقاس الصفحة بدون نزف، وإنه **في نص الورقة بالضبط** (علامات القص حوله)، وإن النزف يغطيه.
5. الجاهزية: الأداة تنتظر الخطوط والصور وهدوء الصفحة. ولو `<html>` فيه `data-ready` بقيمة غير `1` (مثل `data-ready="0"` من البداية)، تنتظر `markReady()` يخليه `1`.
6. ولا طلب برّا المشروع (خط أو صورة من الإنترنت): الأداة تمنعه وتفشل، عشان الملف يطلع نفسه كل مرة.
7. صور السوشال: الورقة بمقاس px صحيح (مثل `width:1080px;height:1080px`). المقاسات لكل منصة من `marketing/telegram-plan.md` §6 (1080×1080، و1024×1024 و1280×720 «غير مؤكد» هناك).

## وش تفحص الأداة
- **الصفحة**: أخطاء السكربت، أي طلب فشل (مثل ملف عميل ناقص 404)، أي طلب برّا، خط ما نزل، أو حروف انرسمت بخط النظام بدل خط القالب (تنبيه). وتطبع تنبيهات القالب نفسه (`.p-warn`).
- **PDF**: عدد الصفحات، ومقاس كل صفحة من `MediaBox` بالمليمتر (الفرق المسموح 0.01mm)، و`TrimBox` و`BleedBox`، ونوع الخطوط، وعدد الصور النقطية داخله.
- **PNG**: المقاس بالبكسل = المليمتر × 96 ÷ 25.4 × الدقة (مثل 45mm في 300dpi = 531px)، والشفافية (وقيمتها في الزوايا الأربع)، و`pHYs` (الدقة داخل الملف: 192 لـ 2x و300 لـ 300dpi، عشان برامج الطباعة تقرا المقاس صح)، وإن الصورة مو فاضية.
- لو فيه خطأ في الصفحة: **ما تصدّر شي** (إلا `--force`).

## اللي لقيناه في المتصفح (قسناه 2026-09-28، Chrome 153 وEdge 154)
- **مقاس صفحة PDF يتقرّب**: 100×70mm يطلع 99.82×69.85، و100×150 يطلع 99.82×149.94، و116×166 يطلع 116.08×166.12. المحتوى نفسه مرسوم بالمقاس الصحيح ومثبت من فوق، فالأداة تصحح `MediaBox` للمقاس الحقيقي وتنزّل المحتوى بالفرق، وتعيد جدول الملف، وتفحصه. بعد التصحيح: 100.000×70.000 و100.000×150.000 و116.000×166.000 (فحص مستقل بـ pypdf).
- **الخط يطلع Type3 في PDF**: حروف Readex Pro مسارات فكتور (حادة بأي مقاس) والنص ينسخ، بس نوعه Type3 لأن ملف الخط متغير (variable). جربنا نسخة ثابتة من نفس الخط: طلعت TrueType مضمّن. هل مطبعتنا تقبل Type3: **غير مؤكد**، يُسأل عنه مع أول بروفة.
- **نسخة الحفر**: الشعار يطلع صورة نقطية داخل PDF (441×90 بكسل في ملصقات المضيف، و432×87 في لوحة الباب، حوالي 300dpi) بسبب `filter: brightness(0)`، والنسخة الملوّنة ما فيها ولا صورة نقطية. الأداة تكتب عدد الصور النقطية في كل PDF.
- **الألوان RGB (sRGB)، مو CMYK**: المتصفح ما يطلّع CMYK. المطبعة تحوّل، والبروفة لازمة (القوالب تنبّه «اطلب بروفة»).
- **حواف ملونة حول النص الصغير (انصلحت 2026-09-28)**: كروم كان ينعّم النص الصغير بالبكسلات الفرعية (LCD)، فيطلع برتقالي على طرف الحرف وأزرق على الطرف الثاني. قسناه في صور لوحات الوحدة: لين 192 في الفرق بين القنوات، و4738 بكسل ملون في مناطق النص الصغير بصورة 300dpi وحدة. العنوان الكبير كان رمادي عادي. الحين الأداة تشغّل المتصفح بـ `--disable-lcd-text`: صفر بكسل ملون في كل الصور. هذا يهم الطباعة (النص الأسود ما يطلع له هالات ألوان) ومشاهد الموقع.
- **لقطة المتصفح تقرّب القص لبكسل CSS كامل** (0.26mm). عشان كذا الأداة تثبت الورقة في زاوية الشاشة، وتصوّر أكبر منها ببكسل، وتقص بنفسها على المقاس بالضبط.
- الأماكن داخل الصفحة تنقرب شوي عند الرسم: نقطة اللمس في PDF ملصقات المضيف طلعت حوالي 0.1mm عن الحساب (قسناها من محتوى ملف PDF). أقل من الفرق المسموح ±0.5mm (`print/README.md`).

## حدود معروفة
- ويندوز بس اللي انجرّب. مسارات ماك ولينكس موجودة بالكود بس ما انجرّبت (**غير مؤكد**).

- صورة الموقع WebP أو AVIF: الأداة تطلّع PNG بس.
