# صور بوت التليجرام (@lamsatap_bot)

10 صور JPEG جودة 85، كل صورة بعرض مختلف (1280 ثم ينقص 10) عشان نميّزها بعد الرفع. التفاصيل (key, width, height, source) في `manifest.json`.
المصادر: `print/social/telegram/png/` وتركيبات `src-composites/` (باركودها وهمي). فحص `tools/check-qr.py` (OpenCV فقط، بدون jsQR): ولا باركود ينقرى في أي صورة.
أُنتجت بـ Python PIL (تصغير LANCZOS بنفس نسبة المصدر). المصادر ما تعدّلت.
طلب صاحب المشروع (2026-09-28): الدائرة المصمتة في 03 و04 و05 و08 تبدّلت بباركود وهمي (25×25 مربع، عيون الزوايا وتوزيع عشوائي، ما ينقرى). نفس فحص check-qr: PASS للأربع.

## خطوات الرفع (لصاحب المشروع)
1. افتح Telegram Desktop أو تليجرام الويب.
2. افتح محادثة @lamsatap_bot.
3. اسحب الصور العشر (01 إلى 10) مرة وحدة داخل المحادثة.
4. اختر «إرسال كصور» (مو ملفات)، وبدون أي تعليق.
5. بلّغنا بعد الإرسال.
