## 2) canvas-design: أصول بصرية بحرفة عالية

### 2.0 وش ناخذ من المهارة، ووش نترك
**ناخذ:**
- **معيار الحرفة:** «كأنه أخذ ساعات ما تنعد، من أحد في قمة مجاله».
  - كل حافة على شبكة البكسل.
  - ولا شي يطلع برّا مكانه، أو يركب على غيره.
  - وحول كل عنصر فراغ.
- **«صقّل، لا تضيف»** (الخطوة الأخيرة في المهارة): نفس فكرة «شيل قطعة» في frontend-design.
- **التكرار والأشكال الكاملة:** حقل الوحدات هو «تراكم العلامات» اللي تتكلم عنه المهارة.
- **ألوان قليلة ومقصودة:** حبر، وأبيض، ورملي، ولمسة وحدة لكل جمهور.
- **الإشارة الخفية** (مثل الموسيقي اللي يقتبس لحن):
  - البابين نص الرمز الفوقاني. اللي يعرف الشعار يشوفه، والباقي يشوف بطاقتين حلوة.
  - والنجمة الرباعية تبقى سر الشعار، وما تتكرر برّاه (§11.4).

**نترك (قواعدنا تغلب، C-12):**
- **ما نخترع «حركة فنية» جديدة:** الهوية محسومة (GM-020 وGM-038 وGM-039 وGM-041 وGM-042).
- **ما ننزّل خطوط:** `canvas-fonts/` كلها لاتينية. نستخدم خطوطنا المحلية بس.
- **المخرج مو png أو pdf:** أصولنا SVG وcanvas وWebP.
- **«الخط رفيع غالباً»:** أوزاننا 400 و500 و700 (§11.3).

**فلسفتنا في سطرين (للحرفة بس، مو هوية جديدة):**
> مادة وحدة: الخانة المربعة. الحقل والباركود والرمز وزاوية الباب، كلها من نفس الخانة، مطبوعة بحبرنا على ورقنا.

### 2.1 قواعد الشعار المقاسة (المرجع لكل أصل)

- **القطع:** 4 قطع متطابقة، كل وحدة مدوّرة 90° عن اللي قبلها.

### 5.1 سكربت الصفحة (للقراءة بس)
- **وين تلصقه:** Console، أو `javascript_tool`، أو `Runtime.evaluate`، على أي صفحة من الثلاث.
- **متى:** بعد ما تخلص الحركة، والصفحة فوق (`scrollY = 0`).
- **وش يسوي:** يفتح الأسئلة المقفولة عشان يقرأ أجوبتها، وبعدها يرجّعها مثل ما كانت.
- **جربته** على البوابة (نسخة 00:15)، على 1440 بكثافة 2 و390 بكثافة 3، واشتغل بدون أخطاء.

```js
(() => {
  const closed = [...document.querySelectorAll('details:not([open])')];
  closed.forEach((d) => { d.open = true; });                       // نقرأ أجوبة الأسئلة بعد، وبعدها نرجّعها
  const vis = (el) => !!(el && el.getClientRects().length) && getComputedStyle(el).visibility !== 'hidden';
  const SKIP = 'svg, .mini, [aria-hidden="true"], script, style, template, noscript';
  const texts = [], nodes = [];
  const tw = document.createTreeWalker(document.body, NodeFilter.SHOW_TEXT);
  for (let n; (n = tw.nextNode());) {
    const p = n.parentElement, s = n.nodeValue.replace(/\s+/g, ' ').trim();
    if (s && p && !p.closest(SKIP) && vis(p)) { texts.push(s); nodes.push(p); }
  }
  const T = texts.join('\n');
  const RISK = 'أسبوعين ببلاش · ما عجبك؟ نشيل العتاد، بدون دفع مقدم ولا التزام في التجربة';
  const rgb = (hex) => 'rgb(' + [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16)).join(', ') + ')';
  const ACCENTS = ['#9A5B00', '#0B7A75', '#F2A93B', '#3FC1B6'].map(rgb);

  r.prices = [...T.matchAll(/([\d][\d.,]*)\s*ريال/g)].map((m) => m[1]);
  r.oldPrices = [...T.matchAll(/(?:^|[^\d.,])(1,199|1199|790|539|429|49|39)(?![\d.,])/g)].map((m) => m[1]);

  r.dotsOutsideRisk = texts.filter((s) => s.includes('·') && !RISK.includes(s) && !s.includes(RISK));
  r.arrowsOrBang = texts.filter((s) => /[→←↗↖➜➔!]/.test(s));
  r.starGlyphs = texts.filter((s) => /[✦✧✨★☆✶✷✸✹✺]/.test(s)).length;
  // FD-5: اللمسة ما تنكتب فيها نصوص
  r.accentText = nodes.filter((p) => ACCENTS.includes(getComputedStyle(p).color)).map((p) => p.textContent.trim().slice(0, 30));
  // FD-4: ولا تباعد حروف على العربي
  r.arabicLetterSpacing = [...new Set(nodes.filter((p) => /[\u0600-\u06FF]/.test(p.textContent) && !['normal', '0px'].includes(getComputedStyle(p).letterSpacing)))]
    .map((p) => p.tagName.toLowerCase() + ' ' + getComputedStyle(p).letterSpacing);
  // FD-3 و §11.1: ولا كبسولة في صفحات الشركة (الأبواب مستثناة لأن زاويتها الكبيرة مقصودة)
  r.pills = [...document.querySelectorAll('body *')].filter((el) => {
    if (el.closest('.mini, [data-door], svg') || !vis(el)) return false;
    const v = getComputedStyle(el).borderTopLeftRadius || '', px = parseFloat(v);
    if (!px) return false;
    const b = el.getBoundingClientRect();
    if (Math.abs(b.width - b.height) <= 1) return false;
    return v.includes('%') ? px >= 50 : px >= Math.min(b.width, b.height) / 2 - 0.5;
  }).map((el) => el.tagName.toLowerCase() + (el.classList.length ? '.' + [...el.classList].join('.') : ''));

    .map((s) => {
      const vb = s.viewBox.baseVal, w = s.getBoundingClientRect().width, sw = parseFloat(s.getAttribute('stroke-width') || '1');
```
