التاريخ: 2026-09-27. مواصفة فقط: لا ربط، لا بناء، لا حسابات. الـ instance: `https://lamsatap.app.n8n.cloud` (خاص بلمسة تاب، منفصل عن أي n8n ثاني — ممنوع لمس أي n8n آخر أو أي أداة MCP لـ n8n في هذه الجلسة).

## الهدف الواحد
`systems/N8N-SPEC.md` تقدر محادثة بناء جديدة تنفذه خطوة خطوة بدون أسئلة.

## المطلوب
1. **sys-architect** → `systems/N8N-SPEC.md` + `sys-architect.md`:
   - الجداول (n8n Data Tables): العملاء، الاشتراكات (الحزم الثلاث من `services/` و`finance/` + تجديد بتأكيد صريح + تذكير 7 و30 يوم، `legal/register.md` بند 18)، الوحدات/الشرائح (من `systems/shortlinks/links.json` مع `type` door/public)، الفواتير والدفعات والدفتر (أعمدة `accounting/*.csv` بالضبط)، العملاء المحتملين (`sales/pipeline.md`). لكل جدول: الأعمدة والأنواع والمفتاح والمصدر ومين يكتب فيه. ممنوع أي عمود لرقم ضيف أو وقت لمسة door.
   - الـ workflows بالأولوية: (أ) واتساب الوارد: تشيك أوت/صيانة → تحويل للمضيف بنص جديد بدون رقم الضيف (بند 21، §8 في `systems/architecture.md`)، (ب) تذكير التجديد، (ج) فاتورة عند تسجيل دفعة (بموافقة صاحب المشروع)، (د) تقرير يومي لصاحب المشروع على واتساب، (هـ) متابعة المبيعات، (و) عداد اللمسات اليومي (public فقط، `systems/tap-counter.md`). لكل واحد: المدخل (trigger)، الخطوات (أنواع العقد بالاسم العام)، الجداول، نقطة موافقة صاحب المشروع، قيود loyer (بنود 20، 21، 23)، وحالات الفشل.
   - مراحل البناء: كل شي غير منشور (GM-006)، ترتيب البناء، ومعيار «جاهز» لكل workflow. النشر قرار صاحب المشروع.
   - التكاليف: اشتراك n8n Cloud بعد التجربة، WhatsApp Business API، رصيد الذكاء الاصطناعي — مصدر رسمي أو «غير مؤكد».
   - ملاحظة مهمة: المرحلة 1 من الواتساب (§8) يدوية بدون API؛ workflow (أ) و(د) و(ب) يحتاجون API أو بديل. وضّح وش يشتغل بدون API.
2. **sys-builder** → `systems/n8n/tables/*.json` (مخطط كل جدول: الاسم والأعمدة والأنواع) + `systems/n8n/seed/` سكربت node بدون مكتبات يحوّل `links.json` و`accounting/*.csv` لـ CSV جاهز للاستيراد في Data Tables (بدون أي رقم جوال حقيقي) + `sys-builder.md`. نسّق مع المعماري: أسماء الجداول والأعمدة في `N8N-SPEC.md` هي المرجع؛ اكتب نسختك وخلّ المختبِر يقارن.
3. **sys-tester** → `sys-tester.md`: يشغّل سكربت seed فعلاً، ويقارن الأعمدة بين المخططات والمواصفة والملفات المصدر، ويتأكد ما فيه عمود ممنوع (رقم ضيف، وقت لمسة door، IP).
