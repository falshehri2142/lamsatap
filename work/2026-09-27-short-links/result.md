# نتيجة القسم: الروابط الثابتة `/t/<code>/` (GM-002 / GM-003)

التاريخ: 2026-09-27. 3 جولات بين sys-architect وsys-builder وsys-tester، وفحص من fact-checker وskeptic.

## الجاهز
- `systems/shortlinks/`: سجل `links.json` + `build.js` (Node بدون مكتبات) → `dist/` (صفحة لكل كود + `_redirects` 302 + صفحة الروابط الملغاة + `404.html`).
- الدومين سطر واحد في `config.json`. روابط تجريبية على example.com فقط.
- حماية: أكواد محجوزة، فحص الوجهة (https، بلا حقن)، منع الوجهة الدائرية، منع حذف كود منشور، تمرير `?src=` فقط، حد 2000 سطر.
- المختبِر: PASS محلياً (curl + محاكاة 404 والحالات الخبيثة).
- `systems/architecture.md`: المعمارية، مقارنة الاستضافات بمصادر، الإحصائيات، وتصميم إشعار التشيك أوت.

## على صاحب المشروع
- يشتري الدومين، ويفتح حساب الاستضافة (المقترح Cloudflare Pages) ويرفع `dist/`، ويربط الدومين.

## غير مؤكد (يُختبر بعد أول نشر حقيقي)
- هل Cloudflare Pages يفرق بين الحروف الكبيرة والصغيرة في المسارات.
- هل `#` في الوجهة ينقرأ تعليق داخل `_redirects`، وهل Cloudflare يمرر `?src=` في تحويل 302.
- قناة إرسال إشعار التشيك أوت (واتساب للأعمال وغيره) وتكلفتها، وهل المزود يسجل الـ IP.
- سماح Cloudflare/Netlify بالاستخدام التجاري بنص صريح؛ ومنع GitHub Pages يحتاج رأي loyer.
