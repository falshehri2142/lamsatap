# sys-architect: الروابط الثابتة

المعمارية الكاملة: `systems/architecture.md` (تصف ما بناه sys-builder).

## اتفاق مع sys-builder
- الطبقتان (`_redirects` 302 + صفحات HTML) صحيحتان وتغطيان الاستضافات الثلاث. 302 وليس 301 صح.
- الدومين في سطر واحد (`config.json`) يحقق معيار النجاح.
- صفحة `inactive` بدل الحذف تحقق قاعدة «لا يُحذف رابط منشور».

## إجابات «غير مؤكد» عند sys-builder (بمصادر)
1. Netlify: المسارات **تفرق بين الحروف** («Paths are case-sensitive» — docs.netlify.com/manage/routing/redirects/overview/). فـ `/t/ABC` يسقط إلى `404.html` ويصححه JS. Cloudflare Pages: التوثيق لا يذكر = غير مؤكد؛ يبقى على sys-tester بعد النشر.
2. `/* /404.html 404`: مدعوم في Netlify (redirect-options). **غير مدعوم في Cloudflare Pages** (يقبل 301/302/303/307/308 فقط — developers.cloudflare.com/pages/configuration/redirects/)، لكن `404.html` يُخدم تلقائياً هناك.
3. GitHub Pages: `404.html` يُعرض للصفحات غير الموجودة (توثيق GitHub الرسمي)، و`_redirects` ليس ميزة موثقة.

## اعتراض واحد (للجولة 2)
أقترح حذف سطر `/* /404.html 404` من `_redirects`: غير ضروري في Netlify وغير مدعوم في Cloudflare (سلوكه الدقيق هناك غير مؤكد: تجاهل أو خطأ).

## الحدود المجانية
مفصلة مع المصادر في `systems/architecture.md` §5. التوصية Cloudflare Pages، واحتياط GitHub Pages.

## إشعار التشيك أوت
تصميم ورقي في §8: الإرسال من نظامنا، مرة كل 6 ساعات لكل وحدة مع تأكيد، «تأكد قبل الدخول»، صفر بيانات عن الضيف، رقم العاملة بموافقتها ويُحذف عند الإلغاء.

## غير مؤكد
حساسية الحروف في Cloudflare Pages، حدود Netlify التفصيلية وما يحصل عند تجاوز الرصيد، قناة الإشعار وتكلفتها، مدة حذف رقم العاملة نظامياً.

## الجولة 3 (بعد المدقق والمشكّك) — حُدّثت architecture.md
1. سطر `/* /404.html 404` انحذف فعلاً؛ الاعتراض أعلاه انتهى.
2. الرابط المعتمد للبرمجة: `https://<domain>/t/<code>/` بشرطة وحروف صغيرة.
3. Cloudflare `_redirects`: 301/302/303/307/308 و200 للمسارات الداخلية، بدون 404.
4. Netlify: نفاد الرصيد يوقف الموقع كله (حد صارم)؛ الدومين الخاص مدعوم؛ الملفات الموجودة تغطي قواعد 302 بدون `!` فالتحويل هناك يصير عبر صفحة HTML.
5. GitHub Pages مشال من الاحتياط: يحتاج رأي loyer (سياسة الاستخدام التجاري). الاحتياط الآن Netlify.
6. حد Cloudflare 2,000 = نحو 1,000 كود.
7. إضافات الباني موثقة في §6: أكواد محجوزة، فحص الوجهة، `published.txt` ضد الحذف، تمرير query.
8. التشيك أوت: كود وحدة عشوائي 12+ حرف، الضغطة المكررة ترسل بعلامة «ضغطة مكررة» ولا تنحجب، حذف رقم العاملة فوري، سجل IP عند المزود غير مؤكد.
