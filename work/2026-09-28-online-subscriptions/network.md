# مشرف الشبكة — الاشتراك والدفع من الموقع (GM-052)
التفاصيل: `sys-architect.md` (المعمارية)، `gateways.md` (المقارنة)، `sys-tester.md` (تحقق المصادر).

1. **التوصية: نعم بشرط** السجل التجاري (GM-002)، وقرار الإطلاق (GM-006)، ونشر الـ sub-workflows الثلاثة (بدونها ما يشتغل شي في n8n).
2. **المسار:** رابط في رسالة التذكير (واتساب أو تليجرام) → صفحة «جدّد اشتراكك» الثابتة → Pages Function تطلب من n8n **رابط دفع مستضاف عند البوابة** بمبلغ الجدول (مو من المتصفح). ما نلمس البطاقة (أقل نطاق PCI، **غير مؤكد** لين تأكيد البوابة).
3. **التأكيد الصريح:** ضغط «جدّد وادفع» + دفع ناجح = `renewal_confirmed_ref = payment:<invoice_no>`. **التجديد التلقائي من البطاقة مؤجل** (يحتاج موافقة مسبقة وتعديل الشروط §4).
4. **Webhook البوابة → n8n:** تحقق التوقيع، ثم **إعادة جلب الدفع من API البوابة** (الحالة والمبلغ والعملة والـ metadata)، ومنع التكرار بـ `gateway_payment_id`. بعدها: فاتورة، و`payments` + قيد سطرين، وتطبيق التجديد، وتنبيه تليجرام، والفاتورة للعميل.
5. **احتياط:** لو الـ webhook ما وصل، n8n يفحص الروابط المفتوحة كل ساعة (اقتراح). مبلغ ما يطابق = لا تسجيل + تنبيه.
6. **حساب بدون كلمة سر:** العميل يكتب رقمه → لو موجود في `clients`، n8n يرسل **رابط دخول لمرة وحدة، صالح 15 دقيقة** على واتساب أو تليجرام (ما نرسل إيميل للعميل) → الـ Function تفتح جلسة (cookie آمنة، 24 ساعة، اقتراح) وتعرض الاشتراك والفواتير بس. نفس الرد سواء الرقم موجود أو لا، ومع حد للطلبات.
7. **الجداول:** `payments`: نضيف `gateway` و`gateway_payment_id` و`gateway_fee_sar` و`settled_at`. `subscriptions`: نضيف `pay_link_id` و`pay_link_expires`. جدول جديد `login_tokens`: الـ hash بس، والانتهاء، و`used_at`، ويتنظف يومياً. ولا جوال ولا IP.
8. **تعارض يحسمه المحاسب:** (ج2) اليوم يطلب موافقة صاحب المشروع قبل تسجيل أي دفعة. اقتراحي: دفعة البوابة المتحقق منها بالـ API تنسجل مباشرة (`owner_confirmed = gateway`)، وصاحب المشروع يوصله تنبيه بس. ورسوم البوابة قيد مصروف عند التسوية.
9. **البوابة (المقارنة تحت):** **Tap** أوضح خيار منشور (مدى 1% بسقف 200 ريال، وروابط دفع). **Moyasar** بديل للعمل الحر، بس أسعارها مو منشورة. الباقي أسعاره من المبيعات. **صاحب المشروع يطلب عروض أسعار مكتوبة من Tap وMoyasar قبل القرار.**
10. **أكبر خطر:** أغلب أرقام البوابات (الفيزا، والتسوية، والـ webhooks، والاشتراكات المتكررة) **غير مؤكدة**. وما فيه عقدة n8n جاهزة لأي بوابة، فالربط يكون بـ HTTP Request (**غير مؤكد**).
11. **الوقت (تقدير):** 2 إلى 3 أيام بناء واختبار بعد اختيار البوابة ووصول مفاتيح بيئة الاختبار. صاحب المشروع يسوي حساب البوابة والتوثيق والمفاتيح بنفسه.
