# الأقفال الذكية لخدمة «فتح الباب من الجوال» — تقرير باحث الموردين
التاريخ: 2026-10-01 · وضع التجهيز فقط (GM-006): ما فيه شراء ولا حسابات ولا رسائل. كل الأسعار **اقتراح/مرجع سوق** مو أسعار معتمدة، وما تنحط في الموقع.

## 1) الخلاصة والتوصية
- **الأساسي: قفل متوافق مع TTLock + بوابة G2 (Wi-Fi)**. رخيص ومتوفر في السعودية، وله Cloud API رسمي فيه أمر فتح عن بعد، ويدعم أكواد مؤقتة تشتغل بدون نت.
- **الاحتياطي / للعميل الفاخر: igloohome** (أكواد algoPIN تشتغل بدون نت إطلاقاً + API رسمي)، لكن سعره أعلى بكثير.
- **غير مناسب حالياً كخيار أول:** Nuki (مصمم لأبواب أسطوانة أوروبية، توفره في السعودية غير مؤكد).
- **مبدأ التصميم:** الشريحة/QR على الباب تفتح رابط → صفحتنا تتحقق من الحجز → سيرفرنا يرسل أمر فتح عبر API ويبلّغنا. **ودائماً** الضيف ياخذ كود PIN مؤقت كبديل لو النت طاح.

## 2) المقارنة
| البند | TTLock (+G2) | igloohome | Nuki Pro |
|---|---|---|---|
| فتح عن بعد بالـAPI | نعم، `v3/lock/unlock` عبر البوابة [1][2] | نعم عبر Bridge / API [5][6] | نعم عبر Wi-Fi المدمج أو Bridge [8] |
| بوابة مطلوبة | G2 (Wi-Fi 2.4GHz) للفتح عن بعد [2][3] | Bridge للفتح عن بعد (غير مؤكد لكل موديل) | Pro فيه Wi-Fi مدمج [8] |
| كود مؤقت بدون نت | نعم (passcode بفترة صلاحية) — آلية الخوارزمية: غير مؤكد تفصيلاً | نعم algoPIN، صلاحيته داخل الكود والقفل يتحقق بدون نت [6][7] | لا يعتمد على هذا (غير مؤكد) |
| سعر في السعودية | قفل بصمة TTLock ~169–218 ر.س، بوابة G2 ~81–159 ر.س على amazon.sa [3][4] | Deadbolt 2S ≈ 969 ر.س (newtechstore) [9] | $199 عالمياً [10]، السعودية غير مؤكد |
| رسوم API | غير مؤكد (يحتاج تسجيل مطوّر في Open Platform، صاحب المشروع هو اللي يسجل) | غير مؤكد (بوابة مطورين self-serve [5]) | لا اشتراك للـRemote Access في Pro [8]، شروط API [11] |
| نوع الباب | موديلات mortise كثيرة تناسب الخشب، وفيه موديلات للألمنيوم/الزجاج (يتأكد بالمقاس) | Deadbolt/Mortise (يحتاج تأكد من المقاس المحلي) | أسطوانة أوروبية — نادر في جدة (غير مؤكد) |

## 3) أبواب شقق جدة
- الشائع: باب خشب بقفل mortise (لسان)، وأبواب ألمنيوم/زجاج في المداخل. **غير مؤكد** كإحصائية — مبني على المعروض في المتاجر المحلية [4][12].
- لازم قبل البيع: قياس سماكة الباب والـbackset ونوع اللسان لكل عميل (نموذج فحص يجهزه القسم).

## 4) التركيب والبطارية
- تكلفة التركيب في جدة: **غير مؤكد** (ما لقينا مصدر منشور؛ يحتاج عرض سعر من فني محلي — صاحب المشروع يطلبه).
- البطاريات: أغلب أقفال TTLock تشتغل بـAA وفيها مدخل USB طوارئ — **غير مؤكد** لكل موديل، نتأكد من ورقة مواصفات الموديل المختار. الـAPI يرجع مستوى البطارية (حقل electricQuantity في TTLock) — غير مؤكد بالرابط، نتحقق من التوثيق [1].

## 5) لو النت طاح (Fallback)
1. كود PIN مؤقت ينرسل للضيف مع تأكيد الحجز (يشتغل بدون نت في القفل) [6][7].
2. بلوتوث من تطبيق القفل (مفتاح إلكتروني) — يحتاج تطبيق، مو مثالي للضيف.
3. مفتاح ميكانيكي احتياطي عند المضيف / صندوق مفاتيح.
4. مراقبة: لو البوابة offline نرسل تنبيه للمضيف (تصميم n8n فقط، بدون نشر).

## 6) الشريحة على الباب: آيفون وأندرويد
- **رابط URL (NDEF) يشتغل على الاثنين:** آيفون XS وأحدث يقرأ الشريحة في الخلفية ويفتح https بدون تطبيق [13][14]. أندرويد بـNFC يفتح الرابط مباشرة.
- **Web NFC ما يشتغل على آيفون:** مدعوم فقط في Chrome/Edge/Samsung على أندرويد، وSafari وiOS لا [15][16].
- النتيجة: الشريحة = رابط فقط، والتحقق والفتح في السيرفر. لا نعتمد على قراءة الشريحة من صفحة الويب. ونضيف QR لنفس الرابط للجوالات القديمة.
- أمان: الرابط ثابت على الباب، فلازم التحقق يكون بالحجز (رمز/OTP يوصل للضيف)، مو بمجرد اللمس. (توصية تصميم، تُراجع مع `nfc-chips` بخصوص شرائح NTAG 424 DNA SUN لو احتجنا رابط متغير.)

## 7) تكلفة تقديرية للوحدة (اقتراح، غير معتمد)

## 8) أسئلة مفتوحة لصاحب المشروع
1. تسجيل حساب مطوّر TTLock Open Platform وigloohome (أنت اللي تسجل) لمعرفة الرسوم والحدود الفعلية.
2. طلب عرض سعر تركيب من فني أقفال في جدة.
3. شراء قفل + بوابة واحدة للتجربة (قرارك، بعد الإطلاق أو كعينة).
4. براندات سعودية محلية بـAPI مفتوح: **غير مؤكد** — ما لقينا مصدر يثبت وجود API عام.
